# 고래·돌고래 언어 연구소 (Cetacean Language Lab)

고래와 돌고래 발성 녹음의 음향 특징을 브라우저에서 탐색하는 실험용 도구입니다.

## 실행

`index.html`을 브라우저로 열거나 상위 폴더에서 서버를 실행하세요.

```powershell
python -m http.server 8000
```

그다음 <http://localhost:8000/whale-lab/>에 접속합니다.

## 제공 기능

- WAV, MP3, OGG, M4A 등 브라우저 지원 음원 불러오기
- 파형 및 스펙트로그램 생성
- 지배 주파수와 스펙트럼 중심 계산
- 에너지 기반 음향 이벤트 및 반복 속도 추정
- 클릭 열, 협대역 휘파람, 지속 변조음의 탐색적 분류
- 실제 녹음 없이 시험할 수 있는 고래·돌고래 합성 신호 4종
- 모든 분석은 브라우저 안에서 수행되며 파일을 업로드하지 않음

## AI 해석을 발전시키는 방법

실제 연구용 AI는 다음 단계를 거쳐야 합니다.

1. 검증된 종·개체·시간·위치 정보가 포함된 수중 녹음을 수집합니다.
2. 발성 구간을 자동 탐지하고 클릭, 휘파람, 노래 등의 임베딩을 학습합니다.
3. 비슷한 발성 단위를 군집화해 반복되는 레퍼토리와 순서를 찾습니다.
4. 먹이 활동, 이동, 사회적 접촉 등 관찰된 행동 메타데이터와 패턴을 대응시킵니다.
5. 보지 않은 개체와 지역의 데이터에서도 같은 대응이 재현되는지 검증합니다.
6. 검증된 범위에서만 “접촉 호출 가능성” 같은 의미 범주를 확률로 제시합니다.

사람의 문장을 학습한 언어 모델만 연결해서 고래 소리를 한국어로 생성하면
그럴듯한 문장을 지어낼 뿐 번역의 과학적 근거가 생기지 않습니다.

## 중요한 한계

이 앱은 고래·돌고래 언어를 번역하거나 모든 종을 식별하지 않습니다. 표시되는
분류는 음향 특징에 기반한 휴리스틱 결과입니다. 실제 종 식별과 행동·의미
해석에는 검증된 학습 데이터, 녹음 위치와 수심, 개체 정보 및 전문가 검토가
필요합니다.
