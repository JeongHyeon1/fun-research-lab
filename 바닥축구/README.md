# NEON FUTSAL x4

한 키보드로 즐기는 2인용 브라우저 풋살 게임입니다.

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

로컬 서버로 실행하려면 이 폴더에서:

```powershell
python -m http.server 8000
```

그다음 <http://localhost:8000>에 접속하세요.

## 조작

- BLUE: `WASD` 이동, `Space` 킥
- RED: 방향키 이동, `Enter` 킥
- `R`: 경기 재시작

먼저 5골을 넣거나 2분이 끝났을 때 점수가 높은 팀이 승리합니다.
